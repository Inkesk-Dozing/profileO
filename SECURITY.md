# Security Policy

## Supported Versions

Only the current main version is supported. No long-term support branches are maintained at this time.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via the contact channels listed below:

- **Primary Contact**: devvindj@gmail.com
- **Response Timeline**: We aim to acknowledge reports within 48 hours and provide detailed follow-up updates.

Please do not open GitHub issues for suspected security vulnerabilities. Use the email address above to submit details in a private, encrypted manner if appropriate.
