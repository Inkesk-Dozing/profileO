# Harsh Dev Jha Portfolio Workspace

Developer portfolio workspace for Harsh Dev Jha, showcasing systems architecture, embedded AI models, and user experience engineering.

## Project Structure

```
profileo/
├── backup/               ← Backup / Original working code
│   ├── index.html        ← Backup HTML Interface
│   └── static/           ← Backup static assets
├── playground/           ← Experimental, planned, and trial versions
│   ├── New-planned-website/
│   ├── claude-storytelling/
│   ├── trial-2/
│   └── trial-versions/
├── static/               ← Main production static files

├── LICENSE               ← Apache 2.0 License
├── SECURITY.md           ← Security reporting protocols
└── CONTRIBUTING.md       ← Contribution guidelines
```

## Quick Start

To view the main portfolio website locally, open the root `index.html` in your web browser, or launch it from your terminal:

```bash
# Direct launch in your default browser:
start index.html
```

To view or test the experimental layouts, check the folders under `playground/` (e.g., `playground/trial-2/index.html`).

## Tech Stack & Architecture

- **Core Elements**: Pure Semantic HTML5, CSS3 Custom Properties (Variables), and Vanilla ES6+ Javascript.
- **Physics particles**: Canvas rendering engine executing attraction/repulsion dynamics on requestAnimationFrame.
- **Live Search**: Instant keypress filtering and DOM manipulation to locate projects and technical tags.
